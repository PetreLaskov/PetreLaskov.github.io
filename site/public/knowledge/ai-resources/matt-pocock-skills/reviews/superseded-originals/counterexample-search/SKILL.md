# Counterexample search

Select the precise claim and the decision relying on it. Use its strongest reasonable interpretation, not an easier substitute.

Identify the conditions under which it should hold. Seek one realistic case satisfying those conditions but defeating the conclusion. Prefer ordinary boundaries and observed mechanisms over exotic hypotheticals. Use evidence or a small test when useful.

For a serious candidate, show conditions, expected behavior, and contradiction. Discard cases already excluded or too implausible to affect the decision.

Return the strongest counterexample, the smallest useful revision, and what action changes. If none is found, describe the bounded search; survival is not proof. Stop when more examples would not change the revision. Do not manufacture objections to perform skepticism.
