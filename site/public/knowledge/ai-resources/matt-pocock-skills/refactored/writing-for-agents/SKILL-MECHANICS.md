# Skill mechanics

Describe the actual capability and discriminating trigger in frontmatter. Keep name and description; preserve supported metadata.

In this Codex target, ordinary discovery is the default for new skills. Preserve existing invocation policy in agents/openai.yaml; use explicit-only selection when the user requests it. The source's disable-model-invocation field serves another harness and is omitted from the target entrypoint.

Split off a skill for a separately useful capability with its own trigger. Keep substantial conditional reference behind pointers; a short skill needs no router.

A wrapper must load dependencies through the available mechanism or read their actual files. A name alone is not loading. Report a missing package rather than pretending it ran. Preserve the shared primitive instead of copying it into each wrapper.
