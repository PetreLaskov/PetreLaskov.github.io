# Issue tracker: GitLab

Record host/project and the supported connector or glab CLI. Read full issue/MR body, notes, labels, author, and state; read the diff for an MR.

Issues and MRs use separate number spaces. Resolve the surface explicitly. GitLab comments are notes; post a closing explanation before closing when the tool does not support a combined operation. Use supported structured or file-backed multiline input.

MRs as a request surface: no. If enabled, record the supported membership check for external-author discovery. Explicitly named MRs are still eligible regardless of discovery filtering.

Publish one issue per spec or ticket. Parent relationships and blockers are distinct. Verify whether native blocking is available for this project/tier; otherwise record explicit Blocked by references and disclose that text is the fallback.

Wayfinding: a map issue with child issue references, map/type labels, blockers, and assignment. Claim before work; resolve by posting the answer, closing the child, and recording a decision pointer in the map. Verify actual CLI/API capabilities and labels when configuring; do not treat a seed example as current-tool evidence.
