# Context choices at a phase boundary

A phase boundary is a useful pause after a meaningful chunk of work. Prefer making context changes there; an urgent context limit can require an earlier checkpoint.

Consider these in order:
1. Continue if the next phase depends on the conversation's precise reasoning and there is practical capacity to finish it. Retaining context also retains noise; do not claim it is costless.
2. Clear only when current working context is irrelevant to what follows and needed decisions are durably available. Verify the host actually supports the action.
3. Hand off when work must travel to a different harness, directory, colleague, or side task. Carry sources, decisions, unresolved questions, and the immediate next action.
4. Delegate when a bounded task can run independently without losing necessary interactive judgment. The parent context remains; the returned report is secondary evidence.
5. Compact when relevant context needs room and the same conversation must continue. State what the next phase needs preserved and retain links to primary artifacts.

Do not use a universal token threshold. Use the host's actual limits, context indicators when available, task size, and signs of lost distinctions. Summaries are useful but lossy; recover the source when a compressed decision becomes consequential.
