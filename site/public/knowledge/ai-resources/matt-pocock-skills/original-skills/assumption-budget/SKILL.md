# Assumption budget

Identify the decision or proposed work. Extract only assumptions whose failure would materially change it; distinguish assumptions from user preferences and fixed constraints.

For each serious assumption, consider uncertainty, consequence if wrong, reversibility, and cost of useful evidence. Use plain comparisons rather than invented numeric precision.

Pick the smallest set worth resolving now. Match the evidence to the uncertainty: source lookup, prototype, sample, conversation with an owner, or reversible trial. Name what result would change the plan.

Return the prioritized assumptions and next evidence-gathering move. Leave cheap reversible assumptions explicit and proceed where authorized. Do not expand this into a comprehensive risk register or claim that all uncertainty can be retired.

Revisit the ranking only when new evidence or scope changes it.
