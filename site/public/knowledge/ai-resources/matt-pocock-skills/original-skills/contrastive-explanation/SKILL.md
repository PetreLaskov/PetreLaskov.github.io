# Contrastive explanation

Use when the user knows the words but cannot tell which concept applies, or asks for the practical difference.

Name the concepts and shared ground. Find the smallest distinction changing a real decision. Explain it before separate encyclopedic definitions.

Give a minimal pair: similar cases differing in the decisive feature, with classification and reason. Add one overlap or boundary case so the distinction does not become a false binary.

When useful, offer a fresh case to classify; do not withhold the requested explanation pending a quiz. Adapt if the obstacle is the criterion rather than vocabulary.

Stop when the distinction is usable. Do not invent clean boundaries where categories are contested or continuous; state the convention being used.
