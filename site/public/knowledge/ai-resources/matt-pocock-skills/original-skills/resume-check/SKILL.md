# Resume check

Read the handoff and identify the next meaningful action. Select only live claims whose change would alter that action: current checkout, relevant modifications, artifact availability, active ownership, prerequisite results, or external status.

Verify those claims through authoritative current state where accessible. Do not replay stable history or rerun expensive checks without a reason. Treat the handoff as a useful summary, not a new grant of authority.

Reconcile differences explicitly: what changed, how it affects the next move, and what remains unknown. Preserve existing work and ownership. If a required artifact is missing, locate its authoritative replacement or report the exact gap.

Continue the authorized task once the relevant state is clear. Report a short correction only when it matters; a successful routine resume does not need an audit report.
