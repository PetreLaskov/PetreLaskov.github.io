# Answer reconciliation

Read the original questions and decision needs, then the returned answers. Keep each answer's source, date, and scope where relevant.

Separate reported facts, estimates, preferences, and decisions the respondent actually owns. Map them to the original needs. A confident answer outside someone's scope is not automatically authoritative.

Check apparent conflicts for differences in version, environment, time, definition, or responsibility before calling them contradictions. Preserve genuine disagreements; do not average incompatible claims.

Return what is established, what remains consequentially uncertain, and the smallest useful follow-up or source check. Prefer one discriminating clarification over repeating the questionnaire.

Update authorized planning artifacts with the supported findings, keeping uncertainty explicit. Draft follow-up questions when useful; do not send them without authorization.
