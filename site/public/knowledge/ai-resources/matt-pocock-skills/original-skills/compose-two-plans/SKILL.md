# Compose Two Plans

Produce a coherent combined plan or recommend choosing one.

1. Read both inputs fully enough to identify each objective, strongest mechanism, commitments, assumptions, and scarce resources.
2. Map compatible elements, redundant elements, and actual conflicts. Do not treat different wording as conflict or shared wording as agreement.
3. Preserve the useful intention of each element, not its exact form. Check dependency order and total demands on time, money, attention, ownership, and technical constraints.
4. For each genuine collision, apply the user's stated priority. If none decides it, recommend a concrete tradeoff and surface the unresolved choice.
5. Write the synthesis as one usable plan with clear responsibilities and sequence. Explicitly name consequential omissions and why they were necessary.
6. Test the result against the original objectives and one realistic execution scenario.

Do not concatenate both plans and call it synthesis. Do not invent a compromise that satisfies neither. If one plan dominates under the actual constraints, say so and retain only justified elements of the other.
