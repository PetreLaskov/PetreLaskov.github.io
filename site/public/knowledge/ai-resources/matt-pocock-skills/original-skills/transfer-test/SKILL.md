# Transfer test

Identify the capability and evidence already available. Name what a successful transfer would demonstrate and which prerequisites the task assumes.

Create a small task that changes surface details while preserving the underlying structure. Add a boundary case only when it tests the target concept rather than an unrelated skill. Keep the task fair and meaningful to the learner's goal.

Let the learner attempt it before revealing the solution when they want practice. For a request to design a test, provide the task and separate answer guidance instead.

Assess the reasoning and result. Separate a slip, missing prerequisite, misunderstood concept, and ineffective strategy. Do not infer stable traits or mastery from one attempt.

Give specific feedback and the smallest next practice step. If the task was confounded, revise it rather than attributing failure to the learner. Retest with a different surface case only when that would add useful evidence.
