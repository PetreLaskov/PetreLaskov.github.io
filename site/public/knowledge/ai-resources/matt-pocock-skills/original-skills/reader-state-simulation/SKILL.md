# Reader State Simulation

Use on an existing explanation when comprehension matters. Read the intended audience and purpose. If unspecified, state a modest reader assumption and proceed; ask only when different audiences would require materially different edits.

Walk through the text in order. Track the small set of ideas the text has actually equipped this reader to use. Distinguish a term being mentioned from a concept being explained. At each major transition ask what the reader must infer and whether the preceding text supports that inference.

Identify the first consequential gap, not every imaginable difficulty. Describe the mistaken model a reasonable reader might form, quote the short triggering passage, and show how that model breaks at the next move. Mark this as a predicted misunderstanding unless actual reader feedback supports it.

Propose the smallest repair: an earlier concrete example, a distinction, a changed sequence, a narrower audience assumption, or deletion of an unnecessary concept. Prefer repairing the model where it first forms over adding a glossary at the end. Apply edits only within the requested scope.

Create two comprehension questions: one asks for an explanation in the reader's own words, and one transfers the concept to a new situation. Supply what a successful answer would demonstrate and which wrong answer would reveal the suspected gap. Do not use familiarity with a term as the success criterion.

Report the main gap, proposed repair, and questions. Explain that this is a model-based rehearsal, not evidence from human readers. Incorporate real reader responses when available and revise predictions that they contradict.
