# Make the Tradeoff Tangible

Create a thinking instrument, not an authoritative prediction.

1. Identify the decision, the few variables the user can change, and the consequence they need to understand.
2. Separate measured inputs, user preferences, and illustrative assumptions. Use a simple model whose relationships can be explained; do not invent empirical precision.
3. Choose the lightest usable artifact: local interactive page, spreadsheet, or another supported control surface. Keep the model and labels visible.
4. Implement meaningful controls and an immediate consequence view. Include units, sensible bounds, and an easy reset. Avoid decorative interactivity.
5. Validate representative and boundary inputs against hand calculations or an independent source. Check that the displayed interpretation matches the model.
6. Let the user explore; explain which conclusions survive across plausible assumptions and which depend on one uncertain value.

Do not build this for a one-step fact or a decision already clear in prose. Do not imply a simulation is observed reality. Success is better understanding of a real dependency or a better-grounded decision, not visual polish alone.
