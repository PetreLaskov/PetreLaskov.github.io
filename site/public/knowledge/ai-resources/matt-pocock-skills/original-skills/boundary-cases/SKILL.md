# Boundary cases

State the proposed rule and why classification matters. Identify competing interpretations rather than assuming the wording has one meaning.

Construct a small set of realistic cases. Prefer minimal pairs differing in one decisive property, plus an ordinary case that should clearly belong and one that should clearly not. Explain why each case is relevant.

Apply the rule and expose inconsistent or surprising results. Ask the user to choose only where the boundary reflects their values or domain authority; investigate factual premises yourself.

Return the clarified rule, its known exception if any, and the smallest set of cases that explains it. Do not force a binary where the subject is continuous or contested. Stop when further cases do not change the boundary.
