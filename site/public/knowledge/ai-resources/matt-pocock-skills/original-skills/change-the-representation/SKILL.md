# Change the Representation

Choose a form that makes the unresolved distinction visible.

1. State the current question and what the current representation hides.
2. Pick one useful transformation: truth table for conditions, state machine for transitions, timeline for ordering, dependency graph for prerequisites, dimensional table for comparison, worked example for abstract rules, or units/equations for quantities.
3. Build the smallest faithful representation from known facts. Mark unknowns instead of filling them with invented detail.
4. Inspect for contradictions, missing states, circular dependencies, incompatible dimensions, or ambiguous boundaries.
5. Translate the resulting insight back into plain language and a concrete decision or next check.
6. Stop if the representation adds no information; try another only for a distinct reason.

Do not force every problem into a diagram. Preserve nuance the chosen form cannot carry in a short note. The purpose is better reasoning, not a more impressive artifact.
