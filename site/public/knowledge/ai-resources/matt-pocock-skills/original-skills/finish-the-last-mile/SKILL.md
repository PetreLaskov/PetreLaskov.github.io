# Finish the Last Mile

Bridge from an existing result to the user's intended use without expanding the task.

1. Identify the promised result and the user's immediate next action: open, run, import, review, send, deploy, or continue editing.
2. Follow that path with the actual artifact where authorized. Check the most likely handoff failure: missing file, broken link, wrong format, inaccessible route, incomplete command, required configuration, or unsupported assumption.
3. Fix small in-scope obstacles directly. If the next action is an external publication or consequential choice not yet authorized, prepare the concrete result and state exactly what remains.
4. Verify the corrected path, not every adjacent possibility.
5. Deliver the usable artifact or exact next action with a concise status. Distinguish created, checked, and externally completed.

Do not add a new onboarding system, documentation suite, deployment, or promotional package unless the request needs it. On a trivial artifact whose use is obvious, skip the skill.

Success is that the user can take the intended next step with less reconstruction, not that the assistant produced a longer closing message.
