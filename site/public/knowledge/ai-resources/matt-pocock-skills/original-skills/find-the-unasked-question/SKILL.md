# Find the Unasked Question

Search for a consequential omission, not more questions for their own sake.

1. State the current decision and intended outcome faithfully.
2. Inspect what is being assumed about purpose, affected people, success, constraints, alternatives, and the cost of doing nothing.
3. Identify at most a few questions whose answers would change the next action. Explain the decision each question controls.
4. Answer factual questions from available evidence where possible. For unresolved preferences or tradeoffs, give concrete alternatives and your recommendation.
5. Integrate the answer into the plan, or state that the original framing remains justified. Respect a user's deliberate choice to keep the scope.

Do not treat every task as secretly misframed. Skip questions that merely add interesting context without affecting action. A useful intervention changes a decision, exposes a material assumption, or strengthens the justification for proceeding.
