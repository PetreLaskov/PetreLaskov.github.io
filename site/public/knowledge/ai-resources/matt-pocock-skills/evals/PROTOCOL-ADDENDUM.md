# Before-trial protocol addendum: no-skill control

A third fresh evaluator will receive the same 114 fixture prompts without any skill package. It will not receive rubrics or source/candidate outputs. This control tests whether apparent improvements are already available from ordinary model behavior. It was added before any behavioral trial outputs existed; case prompts and their original lock are unchanged.

The added condition does not solve cross-case context contamination, one-run uncertainty, prompt cueing, same-family model bias, or the lack of real tool execution. If results saturate, report that limitation rather than assigning causal credit to the refactor. Original proposals receive a separate critical review; their status is not inherited from their source skill's grade.
