# The Return

The summit is not the private opening. The summit is the return - ordinary life, work, relationship, feedback, repair, and service, after the opening has had time to change the person.

This is why Shinzen's [operational enlightenment](operational-enlightenment.md) is so unsentimental. A state is not the test. A story about no-self is not the test. Source language is not the test. The one thing that cannot be counterfeited is conduct over time: less compulsion, more honesty, more repair, more capacity to take correction, more service, and less need to convert experience into rank.

The marketplace matters because it answers back. A private state can be arranged into almost any story you like. Other people, commitments, money, sexuality, illness, fatigue, harm, repair, teaching roles, and power do not cooperate with the story; they expose what it leaves out. If a realization makes ordinary accountability seem beneath you, the realization has been interpreted badly.

The return does not flatten the mystical. It protects it. The deepest openings become trustworthy exactly when they make a person more available to life, not less. If no-self language weakens boundaries, if Source language inflates authority, if equanimity slides into indifference, if service turns into control, the path has quietly looped back into selfing.

"Today's enlightenment is tomorrow's mistake" belongs here. Yesterday's map may have been medicine; today it may be an identity. The return keeps practice honest because life keeps handing over fresh evidence.

So the test is meant to be concrete enough to fail. After a conflict, does repair come easier, or does a fresh spiritual certainty now stand in for the apology? When feedback arrives, can you actually receive it, or does it get waved off as something only the unenlightened would still need? Do ordinary obligations stay visible, or does practice language start excusing neglect? Has service become something concrete for particular people, or has it turned into image management? Is there less compulsive self-protection, or just a subtler status growing up around your realization? None of these asks how deep the opening was. They ask what it did.

You already have the data. It is in how the last hard conversation went, whether the apology got made, whether the people closest to you find you easier to live with since the practice deepened. That is the marketplace, and it answers whether you ask it to or not.

Operational enlightenment is not a promise that the person never suffers or never errs. It is a working direction: identity less automatically captured, behavior less distorted, practice less dependent on special conditions, service more natural, feedback more usable.
