# The Basic Mindfulness System

This old overview has been folded into [The Routes](the-routes.md), [The Sensory Interface](the-sensory-interface.md), and the method pages.

Basic Mindfulness remains useful as a name for Shinzen's older manual architecture: concentration, sensory clarity, and equanimity trained through the Five Ways, the Sensory Grid, Noting, Do Nothing, Nurture Positive, formal and life practice, and Total Happiness. The later See / Hear / Feel interface simplifies that architecture; it does not erase it.
